Le prime istruzioni
Un piccolo sottoinsieme, già compilabile.
void setup() { … }
Eseguito una volta all’avvio.
void loop() { … }
Ripetuto senza chiamate extra.
waitVBlank() · waitVBlank(n)
Attende uno o n VBlank. Zero ritorna subito; n viene valutato una sola volta.
waitFrame()
Alias di waitVBlank(): attende un VBlank.
videoMode(2) · screenDisable() · screenEnable()
Configura Graphics I e controlla lo schermo. vdpWrite(reg, valore) scrive i registri VDP; spriteFlicker(0/1) controlla il flicker.
vramPoke(indirizzo, valore)
Scrive un byte in VRAM.
vramWrite / vramRead(indirizzo, array, offset, lunghezza)
Copia blocchi da/verso array di byte. Offset e lunghezza sono letterali; la lettura richiede RAM.
sound(canale, periodo, volume) · soundVolume(canale, volume)
PSG: canale letterale 0..2 per toni (divisore 0..1023), 3 per rumore (controllo 0..7). Volume 0..15, zero silenzia. soundVolume mantiene il periodo. Nessuna attesa implicita.
controllerRead(1|2)
Stato del controller: su=1, destra=2, giù=4, sinistra=8, fuoco1=64, fuoco2=128. Bit attivo = premuto. Leggi dopo waitVBlank(). Player: P1 frecce + Z/X; P2 WASD + F/G.
clearScreen() · printAt(pos, "testo")
Pulisce lo schermo e stampa testo ASCII.
defineSprite(primo, quanti, dati)
Carica pattern 16×16: 32 byte per sprite.
sprite(n, y, x, pattern, colore)
Aggiorna lo sprite sullo schermo.
Globali uint8_t/uint16_t, array RAM e const ROM indicizzati, + e −, operatori & | ^ ~ e shift costanti; condizioni && || !, if/else, while, do…while e for con break/continue. Switch con case/default, fall-through e return. Funzioni void/uint8_t/uint16_t con parametri scalari per valore e return. Argomenti valutati da sinistra a destra; niente ricorsione.
